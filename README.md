# 실시간 날씨·미세먼지 대시보드 (`26-w10-weather`)

> 이 README는 실습을 완성한 뒤, 배포 직전 단계에서 직접 채워 넣습니다.
> 자세한 실습 절차는 [`guide.md`](./guide.md)를 참고하세요.

## 소개

실시간 날씨 및 미세먼지 정보를 제공하는 React 기반 대시보드입니다.

## 어떻게 만들었나요 (Antigravity IDE 경험)

- 현재 날씨 조회
- 미세먼지(PM10, PM2.5) 조회
- 주요 도시 빠른 선택
- 도시 검색
- 24시간 기온 차트
- 7일 예보
- 반응형 UI

## 데이터는 어떻게 가져오나요 (외부 API 아키텍처)
Open-Meteo API를 사용하여 날씨와 대기질 정보를 조회했습니다.
API 로직은 src/api/weather.js로 분리하여 재사용성을 높였습니다.

## 보안에서 확인한 것 (사이버보안과 체크포인트)
Open-Meteo는 공개 API로 API Key가 필요 없습니다.
비밀 키가 필요한 서비스는 React에서 직접 호출하면 안 되며
백엔드 프록시(BFF)를 통해 호출해야 합니다.
